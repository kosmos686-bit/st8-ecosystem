# 🌐 ST8 Ecosystem | Единая платформа для бизнеса

**ST8 Ecosystem** — это единая платформа, объединяющая три мощных AI приложения для разных отраслей.

## 🎯 Три приложения в одной экосистеме

### 🍽️ **ST8 RESTO**
Персональный AI технолог для ресторана, кафе, пекарни и корпоративного питания.
- Управление меню и рецептурами
- Контроль фудкоста и выручки
- Генерация отчётов
- Анализ меню и позиций

**[Открыть RESTO →](/resto/)**

### 🥘 **Unikfood**
Специализированная система для сетей и производства пищевых продуктов.
- Производственные процессы
- Стандартизация рецептур
- Контроль качества
- Оптимизация затрат

**[Открыть Unikfood →](/resto/unikfood.html)**

### 🏗️ **СТ8 СТРОЙ**
Персональный AI помощник прораба для управления строительством.
- Управление объектами и бригадами
- Документооборот (КС-6а, акты, наряды)
- Контроль дефектов
- Журналы безопасности

**[Открыть СТРОЙ →](/stroy/)**

## ✨ Возможности платформы

| Функция | Описание |
|---------|---------|
| 📱 **PWA** | Установка как приложение на телефон |
| 🤖 **AI** | Генерация документов через Anthropic Claude |
| 💾 **Офлайн** | Service Worker для работы без интернета |
| 🔒 **Приватность** | Все данные хранятся в браузере (localStorage) |
| ⚙️ **Кастомизация** | Полная настройка под вас |
| 📊 **Аналитика** | Графики, отчёты, метрики |
| 📂 **Импорт** | Быстрая загрузка данных из файлов |
| 🔄 **Синхронизация** | Автосохранение всех данных |

## 🚀 Установка

### Как приложение на телефон

**Android/Windows:**
1. Открой приложение в Chrome
2. Нажми "Установить" в адресной строке
3. Приложение появится на home screen 📱

**iPhone:**
1. Открой в Safari
2. Share → Add to Home Screen
3. Готово! 🍎

## 🔧 Требования

- **Браузер:** Chrome, Edge, Safari (актуальные версии)
- **API:** Anthropic Claude (для AI функций)
- **Интернет:** Только для чата с AI
- **Данные:** Хранятся локально в браузере
